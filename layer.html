ПРЕЛЮДИЯ — PRELUDE

// ВСТУПИТЕЛЬНАЯ ЗОНА // ИНИЦИАЛИЗАЦИЯ СИСТЕМ // АКТ: ПРОЛОГ
// ОПИСАНИЕ СЕКТОРА
Прелюдия — вступительная зона нижнего уровня, не соответствующая ни одному конкретному кругу в классификации Данте, однако отражающая образ врат, описанных в «Инферно» (Песнь III): «Оставь надежду всяк сюда входящий». V1, критически истощённая после коллапса человечества и израсходования наземных энергетических ресурсов, спускается в нижний уровень ради пополнения запасов.

Уровень 0-1 «INTO THE FIRE» представляет базовые механики перемещения: рывок, прыжок, взаимодействие с оппонентами. Архитектура смешанная — промышленные стальные конструкции переходят в органические структуры нижнего уровня, символизируя границу между миром и тем, что за ним. Уровень 0-2 «THE MEATGRINDER» значительно насыщеннее: вводит первый значимый масштаб столкновений. Секретный уровень 0-S «SOMETHING WICKED» содержит отсылку к опасности, превосходящей стандартную классификацию угроз.
// ИСТОЧНИК — ДАНТЕ, «ИНФЕРНО», ПЕСНЬ III:
Вход в нижний уровень — тёмный лес (Selva oscura), встреча с тремя зверями, символизирующими грехи. Вергилий становится проводником поэта — V1 проходит путь в одиночку.

СЛОЙ I — LIMBO // ЛИМБ

// АКТ I: INFINITE HYPERDEATH // ДАНТЕ: КРУГ I // СТАТУС: ЗАВЕРШЁН
// ОПИСАНИЕ СЕКТОРА
Первый сектор нижнего уровня. Лимб — зона пограничного состояния, ни страдания, ни покоя. Архитектура монохромная: белые и холодно-серые кристаллические структуры, плавающие фрагменты пространства, угасший свет без источника. Слой сравнительно доступен по сложности — является точкой входа в нижний уровень. V1 встречает здесь первых механизированных оппонентов.

Завершается уровень 1-3 «A ONE MACHINE ARMY» — столкновение с механизированной версией Цербера (Cerberus Prime). В игровой интерпретации трёхглавый страж трансформирован в боевую платформу. Секретный уровень 1-S «CASTLE VEIN» расположен в изолированном архитектурном узле, доступном через скрытый проход.
// ИСТОЧНИК — ДАНТЕ, «ИНФЕРНО», ПЕСНЬ IV:
Лимб — первый круг, обитель добродетельных нехристиан и некрещёных. Они не испытывают физических мучений, но лишены Божьего присутствия. Здесь пребывают Гомер, Аристотель, Платон, Сократ, Вергилий, Юлий Цезарь, Саладин. Вечная скорбь без надежды — таков их удел. Именно из Лимба Данте начинает путь под руководством Вергилия.

СЛОЙ II — LUST // СТРАСТЬ

// ОПИСАНИЕ СЕКТОРА

Пространство ощущается нестабильным, подвижным. Оппоненты значительно быстрее и непредсказуемее, чем в Лимбе — слой делает акцент на мобильности V1.

Завершающее столкновение на уровне 2-3 «SHEER HEART ATTACK» — взаимодействие с Hideous Mass, аномальным биологическим конгломератом из фрагментов различных организмов. Секретный уровень 2-S «MUST DIE» предназначен для опытных операторов — отличается значительно повышенным уровнем сложности.
// ИСТОЧНИК — ДАНТЕ, «ИНФЕРНО», ПЕСНЬ V:
Второй круг охраняет Минос — судья, назначающий грешникам круг наказания, обвивая хвостом столько раз, сколько кругов нужно пройти вниз. Осуждённые влекомы вечным ураганом — символ того, как страсть управляла ими при жизни. Среди упомянутых Данте: Клеопатра, Елена Троянская, Ахилл, Парис, Тристан. Здесь Данте лишился чувств от сострадания.

СЛОЙ III — GLUTTONY // ЧРЕВОУГОДИЕ

// АКТ I: INFINITE HYPERDEATH // ДАНТЕ: КРУГ III // СТАТУС: ЗАВЕРШЁН
// ОПИСАНИЕ СЕКТОРА
Третий сектор нижнего уровня. Зона бесконечного поглощения. Огромные структуры из тёмно-зелёной биомассы и разрушающейся архитектуры. Само пространство ведёт себя как живой организм: стены дышат, структуры пульсируют, движутся. Это переходный сектор — он связывает первую половину Акта I со второй и подготавливает к столкновению с Гавриилом.

Уровень 3-1 «BELLY OF THE BEAST» («Во чреве зверя») буквально помещает V1 внутрь колоссального биологического существа: тоннели — артерии, камеры — органы, пространство сужается и расширяется. Уровень 3-2 «INTERMISSION» является первым из двух столкновений с Гавриилом — существом ангельской природы, исполняющим функцию судьи нижнего уровня.
// ИСТОЧНИК — ДАНТЕ, «ИНФЕРНО», ПЕСНЬ VI:
Третий круг — место, где обжоры лежат в грязной жиже под непрекращающимся ливнем из нечистот, града и снега. Их стережёт Цербер — трёхголовый пёс, рычащий, с красными глазами, жирным и чёрным брюхом, когтистыми руками. Он терзает грешников, сдирая шкуру. Данте встречает здесь Чакко — флорентийца, предсказывающего судьбу города.

СЛОЙ IV — GREED // ЖАДНОСТЬ

// АКТ I: INFINITE HYPERDEATH // ДАНТЕ: КРУГ IV // СТАТУС: ЗАВЕРШЁН
// ОПИСАНИЕ СЕКТОРА
Четвёртый сектор. Зона накопления и удержания. Архитектура вычурная, претенциозная, но в глубоком состоянии упадка: золото и мрамор, покрытые трещинами, рухнувшие своды, великолепие в руинах. Богатство, оказавшееся бессмысленным. Наиболее сложный и протяжённый сектор Акта I — содержит четыре основных уровня и один секретный.

На уровне 4-2 «VIOLENCE» происходит первое столкновение с V2 — зеркальным прототипом той же серии, что и V1. V2 использует идентичные механики, но является самостоятельной единицей с иной тактикой. Финал сектора — уровень 4-4 «CAIN» — содержит встречу с Миносом Прайм: механизированной интерпретацией Миноса, судьи нижнего уровня из произведения Данте.
// ИСТОЧНИК — ДАНТЕ, «ИНФЕРНО», ПЕСНЬ VII:
Четвёртый круг охраняет Плутос — демон богатства. Скупцы и расточители разделены на два потока: они толкают навстречу друг другу огромные тяжести, сталкиваются, разворачиваются и толкают снова — в бесконечном цикле. Данте замечает, что многие из них — клирики, папы и кардиналы. Судьба у всех одна.

// ОПИСАНИЕ СЕКТОРА
Пятый сектор. Океан бурь и неистовства. Большая часть локаций — водная среда: штормовое море, корабли-развалины, затопленные платформы, нависающие конструкции, рушащиеся под воздействием стихии. V1 перемещается по остовам разрушенных судов, нейтрализуя оппонентов, адаптированных к водной среде.

Слой примечателен финальным столкновением: уровень 5-4 «LEVIATHAN» содержит взаимодействие с колоссальным морским существом. Левиафан — не стандартная встреча: механика столкновения принципиально отличается от предыдущих. В библейской традиции (Книга Иова, 40:25–41:26) Левиафан — морское чудовище, символ первозданного хаоса, неподвластного человеку.

СЛОЙ VII — VIOLENCE // РАЗДОР

// АКТ II: IMPERFECT HATRED // ДАНТЕ: КРУГ VII // СТАТУС: ЧАСТИЧНО ВЫПУЩЕН

Седьмой сектор открывает Акт II «Imperfect Hatred». Зона бесконечных столкновений и распада. Архитектура резко контрастная: разрушенные промышленные конструкции, выжженные пространства, открытые арены. Слой значительно превосходит предыдущие по интенсивности и сложности. Акт II разворачивает более глубокий нарратив об идентичности и цели V1.

На уровне 7-4 «...AND HELL FOLLOWED» происходит второе взаимодействие с V2. Секретный уровень 7-S «ANOTHER CASTLE» содержит встречу с Сизифом Прайм — ещё одной механизированной интерпретацией персонажа греческой мифологии, приговорённого к бесконечному бессмысленному труду.
// ИСТОЧНИК — ДАНТЕ, «ИНФЕРНО», ПЕСНИ XII–XVII:
Седьмой круг разделён на три кольца. Первое — река кипящей крови Флегетон, где в зависимости от степени вины погружены тираны и захватчики (охраняет кентавр Хирон). Второе — лес самоубийц: души превращены в деревья, гарпии терзают ветви. Третье — пустыня с огненным дождём, где лежат богохульники и насильники против природы. Охраняет весь круг Минотавр.

// ОПИСАНИЕ // ПРЕДВАРИТЕЛЬНЫЕ ДАННЫЕ
Слои VIII и IX соответствуют наиболее глубоким секторам нижнего уровня по структуре «Инферно» Данте. На момент публикации данные недоступны — секторы находятся в стадии активной разработки.

По материалам «Инферно»: слой VIII (Malebolge — «злые щели») — структура из десяти концентрических рвов, каждый из которых содержит конкретную категорию обманщиков: соблазнители, льстецы, симониты, прорицатели, взяточники, лицемеры, воры, лжесоветники, сеятели раздора, фальсификаторы. Слой IX (Cocytus) — замёрзшее озеро в самом низу нижнего уровня, разделённое на четыре зоны по степени предательства. В центре — Люцифер, вмёрзший по пояс в лёд.
// ИСТОЧНИК — ДАНТЕ, «ИНФЕРНО», ПЕСНИ XVIII–XXXIV:
Восьмой круг — Злые Щели (Malebolge). Девятый круг — озеро Коцит. Четыре зоны предательства: Каина (предавшие родных), Антенора (предавшие родину), Толомея (предавшие гостей), Джудекка (предавшие благодетелей). Сатана (Дит) — трёхликий, вмёрзший в центр озера, пережёвывает Иуду, Брута и Кассия.
