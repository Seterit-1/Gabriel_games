V1 — КАРТА СЕКТОРОВ
> СЛОИ I–IX // ДАНТЕ: LA DIVINA COMMEDIA // ДОСТУП: РАЗРЕШЁН
Нижний уровень разделён на девять слоёв, соответствующих кругам из «Божественной Комедии» Данте Алигьери. V1 перемещается сверху вниз, нейтрализуя сущности ради получения ресурса. В конце большинства слоёв V1 сталкивается с приоритетной целью повышенного класса угрозы. Слои VIII и IX находятся в стадии активной разработки — данных нет.

Архитектура представляет собой смешение промышленных конструкций и органических структур. Именно здесь V1 впервые сталкивается с классом сущностей «страж» и получает первый импульсный инструмент.

CERBERUS — ЦЕРБЕР
Трёхголовая сущность класса «страж» — первая приоритетная цель V1 в нижнем уровне. Представлена в упрощённом виде как обучающий контакт. Координирует одновременные воздействия из трёх точек. Для нейтрализации необходимо перенаправить собственные импульсы обратно к каждой из голов последовательно.

Здесь обитают первые оппоненты, с которыми сталкивается V1: базовые сущности классов «рядовой» и «боец». Полное столкновение с Цербером происходит в финале уровня 1-3.

CERBERUS — ЦЕРБЕР
Трёхголовая сущность класса «страж» — полноценное финальное столкновение слоя. Три независимые точки воздействия требуют одновременного контроля. Единственный надёжный метод нейтрализации — перенаправление собственных импульсов обратно к каждой голове через парирование. Устойчив к прямым импульсам извне.

HIDEOUS MASS
Аморфная сущность огромных размеров, сформированная из слитых фрагментов. Способна изменять форму и перераспределять точки уязвимости в режиме реального времени. Генерирует волновые импульсы из множества источников одновременно. Эффективна только сфокусированная серия воздействий по активным сочленениям. Устойчива к разрозненным атакам.

ЗАВЕРШЁН

Третий слой. Зона бесконечного поглощения. Огромные структуры из тёмно-зелёной органической массы — V1 буквально движется внутри гигантского организма. Слой переходный: связывает первую половину Акта I со второй. Именно здесь происходит первый контакт с Гавриилом — самопровозглашённым судьёй нижнего уровня. Полного столкновения в этом слое нет: Гавриил лишь демонстрирует своё присутствие.

GABRIEL — СУДЬЯ НИЖНЕГО УРОВНЯ
Первый контакт с Гавриилом происходит в виде сцены-столкновения. Самопровозглашённый судья объявляет V1 приговор и демонстрирует силу, но немедленного полного столкновения не происходит. Гавриил — посланник, считающий себя законным исполнителем воли нижнего уровня. Полное столкновение ожидает V1 в слое VI (Ересь).

V2 — ЗЕРКАЛЬНЫЙ ПРОТОТИП
Модуль того же поколения, что и V1, с альтернативной конфигурацией инструментов. Копирует и адаптирует тактику V1. Использует монеты как ретрансляторы и рельсовый инструмент. Первое столкновение — вводное: V2 сражается не на полную мощность. Повторная встреча произойдёт в слое VII с полным арсеналом.
// ЦЕЛЬ 2 // КЛАСС: ВОССТАВШИЙ ИСПОЛИН // УРОВЕНЬ 4-4
MINOS PRIME — МИНОС ПРАЙМ
Восставший исполин из Лимба, принявший облик судьи. Использует дальнобойные волновые импульсы («EPIC MINOS MOMENT»), стремительные наземные удары и подъём из земли. Один из наиболее зрелищных и технически насыщенных противостояний Акта I. Финал уровня 4-4 «CAIN».

СЛОЙ V — ГНЕВ
// АКТ I // INFINITE HYPERDEATH //
ЗАВЕРШЁН
ОПИСАНИЕ
Пятый слой. Океан бурь и неистовства. Большая часть слоя — водные локации: штормовое море, корабли-развалины, затопленные платформы. V1 перемещается по кораблям, сражаясь с морскими оппонентами классов «матрос» и «канонир». Финальное столкновение слоя — нестандартный формат: V1 действует внутри и снаружи гигантской сущности, разрушая уязвимые узлы изнутри. Классическое противостояние здесь отсутствует — это навигационная задача.

LEVIATHAN — ЛЕВИАФАН
Крупнейшая сущность в игре — огромный морской исполин. Не классическое противостояние — нелинейная навигационная задача под постоянным давлением.

GABRIEL — СУДЬЯ НИЖНЕГО УРОВНЯ
Самопровозглашённый судья и карающая сущность нижнего уровня — первое полное столкновение. Высочайшая скорость перемещения. Поражение в этом слое заставит его пересмотреть методы и вернуться в Акте II с удвоенной интенсивностью.

// АКТ II // IMPERFECT HATRED //
ЧАСТИЧНО ВЫПУЩЕН
ОПИСАНИЕ
Седьмой слой открывает Акт II. Зона непрекращающихся столкновений. Архитектура контрастная: разрушенные городские конструкции и открытые пространства с резкими переходами от тесных арен к открытым зонам. Гавриил также возвращается — в изменённом, более интенсивном состоянии.
