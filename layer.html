// АКТ II / АКТ III // ДАНТЕ: КРУГИ VIII–IX // СТАТУС: В РАЗРАБОТКЕ
// ПРЕДВАРИТЕЛЬНЫЕ ДАННЫЕ
Слои VIII и IX соответствуют наиболее глубоким секторам нижнего уровня по структуре «Инферно» Данте. На момент публикации данные недоступны — секторы находятся в стадии активной разработки.

По материалам «Инферно»: слой VIII (Malebolge — «злые щели») — структура из десяти концентрических рвов, каждый содержит конкретную категорию обманщиков: соблазнители, льстецы, симониты, прорицатели, взяточники, лицемеры, воры, лжесоветники, сеятели раздора, фальсификаторы. Слой IX (Cocytus) — замёрзшее озеро в самом низу нижнего уровня, разделённое на четыре зоны по степени предательства. В центре — Люцифер, вмёрзший по пояс в лёд.
// ИСТОЧНИК — ДАНТЕ, «ИНФЕРНО», ПЕСНИ XVIII–XXXIV:
Восьмой круг — Злые Щели (Malebolge). Девятый круг — озеро Коцит. Четыре зоны предательства: Каина, Антенора, Толомея, Джудекка. Сатана (Дит) — трёхликий, вмёрзший в центр озера, пережёвывает Иуду, Брута и Кассия. Данте и Вергилий выбираются через тело Люцифера к звёздам.
