Архитектура смешанная: промышленные конструкции переплетаются с органическими структурами. В этом секторе V1 использует ограниченный арсенал — полный доступ открывается позже.

SWORDSMACHINE
// УРОВЕНЬ 0-2 // THE MEATGRINDER
Первая серьёзная приоритетная цель в игре. Высокомобильная сущность, вооружённая клинком. Комбинирует стремительные сближения с дальнобойными импульсами. Имеет режим защиты: при получении воздействия в определённые промежутки активирует щитовой режим. Парирование нейтрализует щит.
SOMETHING WICKED
// УРОВЕНЬ 0-S // SOMETHING WICKED // СЕКРЕТНЫЙ
Неизвестная сущность секретного уровня. Не является стандартной целью — скорее предупреждение и предзнаменование. Не нейтрализуется стандартными средствами. Цель — избежать контакта.

CERBERUS (ЦЕРБЕР)
// УРОВЕНЬ 1-3 // A ONE MACHINE ARMY
Трёхголовая сущность класса «страж». Каждая голова функционирует как отдельный источник воздействия. Генерирует парируемые энергетические импульсы в трёх направлениях. Стратегия нейтрализации: своевременное перенаправление импульсов обратно к соответствующей голове.
SWORDSMACHINE (ПОВТОРНЫЙ)
// УРОВЕНЬ 1-2 // THE DEATH OF THE PARTY
Повторная встреча. В этот раз действует совместно с другой аналогичной единицей — тандем значительно усложняет взаимодействие.

HIDEOUS MASS

Аморфная сущность колоссальных размеров, сформированная из слитых воедино фрагментов органической материи. Способна изменять конфигурацию тела. Имеет множество сочленений — каждое является уязвимой точкой. Наиболее эффективная тактика: концентрация воздействий на отдельных сегментах.

GABRIEL — ПЕРВЫЙ КОНТАКТ
// УРОВЕНЬ 3-2 // INTERMISSION
Самопровозглашённый судья нижнего уровня. В слое III происходит первый контакт — Gabriel появляется перед V1 и демонстрирует своё присутствие, однако полноценного столкновения ещё не происходит. Это вступление к главной встрече в слое VI.
