Прелюдия — вводная зона, не соответствующая отдельному кругу в системе Данте, однако отражающая образ врат из «Инферно» (Песнь III): «Lasciate ogni speranza, voi ch'entrate» — «Оставь надежду всяк сюда входящий». V1, истощённая после коллапса человечества, спускается в нижний уровень ради пополнения энергетических запасов.

Уровень 0-1 «INTO THE FIRE» обучает базовым механикам. Уровень 0-2 «THE MEATGRINDER» представляет первую масштабную серию взаимодействий. Архитектура переходная: промышленные конструкции сменяются органическими структурами нижнего уровня — граница между мирами.

СЛОЙ I — LIMBO // ЛИМБ

// АКТ I: INFINITE HYPERDEATH // ДАНТЕ: КРУГ I // СТАТУС: ЗАВЕРШЁН
// ОПИСАНИЕ СЕКТОРА
Первый сектор нижнего уровня. Лимб — зона пограничного состояния: ни страдания, ни покоя. Монохромная белая архитектура, кристаллические структуры, угасший свет без источника. Наиболее доступный сектор — точка входа в нижний уровень. V1 встречает здесь первых механизированных оппонентов.

Столкновение на 1-3 «A ONE MACHINE ARMY» — с Cerberus Prime, механизированной трёхголовой платформой. Секретный уровень 1-S «CASTLE VEIN» расположен в изолированном архитектурном узле.
// ДАНТЕ, «ИНФЕРНО», ПЕСНЬ IV — ПЕРВЫЙ КРУГ:
Обитель добродетельных нехристиан и некрещёных. Без мучений, но без Бога — вечная скорбь. Жители: Гомер, Аристотель, Платон, Сократ, Вергилий, Цезарь, Саладин. Они живут в замке с семью вратами — символе семи добродетелей — среди прекрасного луга.

Столкновение 2-3 «SHEER HEART ATTACK» — с Hideous Mass, биологическим конгломератом из фрагментов различных организмов. Секретный 2-S «MUST DIE» — для опытных операторов.

Уровень 3-1 «BELLY OF THE BEAST» («Во чреве зверя») буквально помещает V1 внутрь колоссального существа: тоннели — артерии, камеры — органы. Уровень 3-2 «INTERMISSION» — первое взаимодействие с Гавриилом, судьёй ангельской природы.

// ОПИСАНИЕ СЕКТОРА
Океан бурь. Большая часть локаций — водная среда: штормовое море, корабли-развалины, затопленные платформы. V1 перемещается по остовам разрушенных судов. СЛОИ VIII–IX — FRAUD & TREACHERY

// АКТ II / III // ДАНТЕ: КРУГИ VIII–IX // В РАЗРАБОТКЕ
// ПРЕДВАРИТЕЛЬНЫЕ ДАННЫЕ
Слои VIII и IX — наиболее глубокие секторы нижнего уровня. Данные не выпущены.

По структуре «Инферно»: слой VIII (Malebolge) — «злые щели», десять концентрических рвов для различных категорий обманщиков (соблазнители, льстецы, симониты, прорицатели, взяточники, лицемеры, воры, лжесоветники, сеятели раздора, фальсификаторы). Слой IX (Cocytus) — замёрзшее озеро, четыре зоны предательства: Каина, Антенора, Толомея, Джудекка. В центре — Люцифер, вмёрзший по пояс, пережёвывающий Иуду, Брута и Кассия.
// ДАНТЕ, «ИНФЕРНО», ПЕСНИ XVIII–XXXIV:
Cocytus — последнее место. Холод вместо пламени: лёд — символ полного отсутствия тепла любви. Сатана (Дит), трёхликий, машет крыльями и тем самым поддерживает вечный мороз. Данте и Вергилий выбираются через тело Люцифера и возвращаются к звёздам.
