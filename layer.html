PRELUDE — ПРЕЛЮДИЯ

// ОПИСАНИЕ
Вступительная зона нижнего уровня. V1 только прибыла: ресурсные запасы критически малы, системы не прогреты. Прелюдия знакомит с базовыми механиками перемещения и взаимодействия. Архитектура смешанная: промышленные конструкции переплетаются с органическими структурами. В секторе V1 использует ограниченный арсенал — полный доступ открывается позже.

SWORDSMACHINE
// УРОВЕНЬ 0-2 // THE MEATGRINDER
Первая серьёзная приоритетная цель. Высокомобильная сущность, вооружённая клинком. Комбинирует стремительные сближения с дальнобойными импульсами. Имеет щитовой режим, нейтрализуемый парированием. Встречается в нескольких вариациях по ходу игры.
SOMETHING WICKED
// УРОВЕНЬ 0-S // СЕКРЕТНЫЙ
Неизвестная сущность секретного уровня. Нейтрализации стандартными средствами не поддаётся. Цель — избежать контакта. Природа и происхождение намеренно не раскрываются.
I
LIMBO — ЛИМБ
ДАНТЕ: КРУГ I // ЗОНА ОЦЕПЕНЕНИЯ
АКТ I ЗАВЕРШЁН ▶
// ОПИСАНИЕ
Первый слой нижнего уровня. Лимб — зона оцепенения, пограничное состояние. Архитектура монохромная: белые и серые кристаллические структуры, плавающие фрагменты пространства. Входная точка в нижний уровень. Относительно доступный по сложности — позволяет V1 адаптироваться к новым условиям.

// ОСНОВНЫЕ СУЩНОСТИ
CERBERUS (ЦЕРБЕР)
// УРОВЕНЬ 1-3 // A ONE MACHINE ARMY
Трёхголовая сущность класса «страж». Каждая голова является отдельным источником парируемых энергетических импульсов. Стратегия: перенаправление импульсов обратно к соответствующей голове с точным таймингом. При нейтрализации одной головы темп воздействий остальных возрастает.
SWORDSMACHINE — ТАНДЕМ
// УРОВЕНЬ 1-2 // THE DEATH OF THE PARTY
Повторная встреча: два экземпляра одновременно. Один использует клинок, второй — дальнобойный модуль. Тандем значительно усложняет взаимодействие по сравнению с Прелюдией.

// ОПИСАНИЕ
Второй слой. Зона неистовства и неудержимого порыва. Органическая тёмно-розовая архитектура: пульсирующие стены, извивающиеся коридоры. Оппоненты значительно быстрее, чем в Лимбе. Слой проверяет мобильность V1 и скорость реакции.

HIDEOUS MASS
// УРОВЕНЬ 2-3 // SHEER HEART ATTACK
Аморфная сущность колоссальных размеров из слитой органической материи. Меняет конфигурацию тела и траектории импульсов. Множество сочленений — каждое является уязвимой точкой. Эффективная стратегия: концентрация воздействий на отдельных сегментах. Нейтрализация сегментов ограничивает возможности сущности.
III

GABRIEL — ПЕРВЫЙ КОНТАКТ
// УРОВЕНЬ 3-2 // INTERMISSION
Самопровозглашённый судья нижнего уровня. Первый контакт: Gabriel появляется перед V1, объявляет её целью своего правосудия, однако полноценного столкновения не происходит. Золотые доспехи, крылатый силуэт. Предвестник главной встречи в слое VI.

V2 — ПЕРВОЕ СТОЛКНОВЕНИЕ

MINOS PRIME
// УРОВЕНЬ 4-4 // CAIN
Восставший исполин из Лимба, некогда бывший судьёй нижнего уровня. Гигантские волновые импульсы, стремительные наземные воздействия, прыжковые удары. Большинство импульсов парируемы. Одно из наиболее известных столкновений в игре. Финальная фаза включает воздушные воздействия.
